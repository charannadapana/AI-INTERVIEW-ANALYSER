# AI Automated Interview Analyzer Deployment Guide

This guide covers how to deploy the AI Automated Interview Analyzer project to a cloud platform like **Render**, **Heroku**, or **PythonAnywhere**.

Since we are using Python and Flask, the easiest and most modern deployment approach is using [Render.com](https://render.com) (which offers a free tier).

---

## 1. Prerequisites (What you need)

Before deploying, ensure you have the following ready:
1. A **GitHub Account** (https://github.com)
2. A **Render Account** (https://render.com)
3. Download/Install **Git** on your local machine if you haven't already.

---

## 2. Prepare the Project for Deployment

The project needs a few minor configurations so the cloud server knows how to run it. 

### A. Requirements File
The cloud server needs to know what Python packages to install. I have automatically generated a `requirements.txt` file for you in the project folder. You do not need to do anything here.

### B. WSGI Server (Gunicorn)
Flask's built-in server is not meant for production. We must use a production server like `gunicorn`.
Open your terminal inside the `c:\Users\simha\OneDrive\Desktop\NLP` folder and run this command to add it to your requirements:
```bash
.\venv\Scripts\python -m pip install gunicorn
.\venv\Scripts\python -m pip freeze > requirements.txt
```

---

## 3. Uploading to GitHub

Cloud services pull your code directly from a code repository like GitHub. 

1. Go to **GitHub** and create a new repository (name it something like `ai-interview-analyzer`). **Do not add** a README, .gitignore, or license initially.
2. Open your terminal in the project folder (`c:\Users\simha\OneDrive\Desktop\NLP`) and run the following commands sequentially:

```bash
# Initialize a local Git repository
git init

# (Optional but recommended) Create a .gitignore file so you don't upload the virtual environment or the local database
echo venv/ > .gitignore
echo __pycache__/ >> .gitignore
echo database.db >> .gitignore
echo uploads/ >> .gitignore

# Add all project files
git add .

# Commit the files
git commit -m "Initial Deployment Commit"

# Link your local repo to GitHub (Replace YOUR_USERNAME and YOUR_REPO_NAME correctly)
git branch -M main
git remote add origin https://github.com/Simhadri1426/ai-interview-analyzer.git

# Push the code to GitHub
git push -u origin main
```

---

## 4. Deploying to Render (Free Cloud Hosting)

Once your code is successfully on GitHub, you can deploy it to the web.

1. Go to your **Render dashboard** (dashboard.render.com).
2. Click the **"New +"** button in the top right and select **"Web Service"**.
3. Under "Build and deploy from a Git repository", click **Next**.
4. Connect your GitHub account, search for the repository you just created (`ai-interview-analyzer`), and click **Connect**.
5. Fill in the following details for your web service configuration:
   - **Name:** ai-interview-system
   - **Region:** Ohio (or your closest region)
   - **Branch:** `main`
   - **Runtime:** `Python 3`
   - **Build Command:** 
     ```
     pip install -r requirements.txt && python -m textblob.download_corpora
     ```
   - **Start Command:**
     ```
     gunicorn app:app
     ```
6. Scroll down to the bottom and select the **Free** instance type.
7. Click the **"Create Web Service"** button.

---

## 5. You're Live! 🌍

Render will now begin building your application. You will see logs scrolling on the screen. It usually takes about **2 to 5 minutes** for the first build. 

Once it says "Live" in green, you can click the `*.onrender.com` URL at the top of the page. Your AI Interview Analyzer is now fully deployed and accessible on the internet for candidates and HR teams to use!

### Important Deployment Notes:
- **Database:** Since we are using local SQLite (`database.db`), the database will reset whenever Render restarts your free server. For a completely permanent, scalable production app, you would eventually swap SQLite for a cloud **PostgreSQL** database URL (Render offers free Postgres databases).
- **Audio Files:** The temporary `.wav` files generated by candidates are saved in the `uploads/` folder. Render's free tier has an ephemeral (volatile) file system, meaning these audio files exist while the server is awake but get deleted if the server idles. This is perfectly fine since standard NLP processing occurs immediately upon submission! 

Good luck with your interviews!
